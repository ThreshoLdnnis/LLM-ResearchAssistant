# 从第一个 PDF 到可复核的研究结论

| 步骤 | 动手任务 | 过关标准 |
|---|---|---|
| 1　核原表 | 打开年报摘要第 3 页，手记三年集团净利润和归母净利润 | 写清单位，并指出同比变化列夹在哪两个年度之间 |
| 2　建库 | 按 README 安装，执行 demo、list，打开一个 PDF 页码链接 | 识别公司、报告年度、披露日、来源类型和物理页码，确认 4 份 51 页 |
| 3　查数 | 执行 series 比较 revenue、net_profit、parent_profit | 逐列对照手记，解释净利润增长与营收下降如何同时成立；原因另找管理层原文 |
| 4　查原因 | 对同一问题运行 bm25、vector、hybrid、rerank | 记录前五块，第一个命中在哪一位，命中页上返回的那句话是否回答了问题 |
| 5　审模型 | 打开 bench/review.json，对照输出重评 a01、a02 | 分开判断每股与总额、答案正确与具体引文支持，保留分歧理由 |
| 6　做研究 | 添加另一家公司的报告，先盲标问题、可接受来源与数据，再冻结代码运行实验 | 按公司或期间留出测试集，报告每种方法的分子分母、差值及失败题；保留原基准不动 |

**练习。** 把“2024 年招商银行 ROE 是多少”改写成可检验的问题，写明集团或母公司、归属对象、加权或平均口径、是否扣非。再查看报告是否支持这些限定。即使两个口径在某年碰巧数值相同，也应保留分别对应的行名。

**项目 06 如何接数据。** 从本项目导出 doc、page、label、scope、period、unit、value、quote，回表确认并保留披露日。将管理层解释及券商预测分别归档，再由公司研究项目决定采用哪些假设和估值方法。

## 第一次独立复核

1. 在年报摘要第 3 页手工抄录 2022、2023 和 2024 年的营业收入。参考值分别是 344,783、339,123、337,488，单位为人民币百万元。用 337,488 除以 339,123 后减一，得到 2024 年同比约 −0.48%。把过程与 `python -m finrag series cmb-fy24 revenue` 对照。
2. 保持同一页，分别找出集团净利润和归属于本行股东的净利润。前者 2024 年同比约 +1.05%，后者约 +1.22%。请用一句话描述已经观察到的变化，再另写一句需要补充来源才能成立的原因解释。
3. 切换到分红公告。手记“人民币元/股”“亿元合计”“A 股合计”三个口径。运行一次模型问答，然后遮住正文，仅根据模型选的引文重新作答。记录你能不能复核它的分母。
4. 做一次单变量实验。用 `python -m bench.evaluate --output data/local/practice` 重新生成记录，选 r16，在相同分块条件下对照四种排序。写下遗漏的是公司披露还是券商解释。这比给一组没有分母的准确率更能说明错误如何影响研究结论。

**交给导师复核的作业**是九个原始数值及页码、一张四种检索方法的同题对照表、一个错误引用反例和一段有适用范围的结论。只用已披露事实解释你观察到的结果。原表、实验参数与评分理由均可沿链接追踪。[来源清单](../data/sources.json) · [评估报告](EVALUATION.md) · [论文](PAPER.md)
