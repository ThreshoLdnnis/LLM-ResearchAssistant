# 六家公司公开披露的导入与首轮核验

本批覆盖招商银行、兴业银行、美的集团、格力电器、贵州茅台和五粮液。每家公司取 2022–2024 年三份年报全文、一份 2024 年三季报及一份 2024 年度分红实施公告。30 份文件的 SHA-256、PDF 物理页数和来源均与[采集清单](collection-manifest.json)相符。原有四份招商银行演示材料与这批文件重叠两份；同时导入两个集合可得到 32 份不同的文档。

## 可直接使用的数据

- [核对底表（CSV）](../results/collection-reference.csv)含 72 行。54 行是 18 份年报各自披露的营业收入、归母净利润和经营活动现金流量净额，记录本期与比较期原数。另有 12 行单季或前三季累计营业收入，及 6 行 A 股年度分红实施金额。每行保留原单位、物理页码、原件链接及指纹。
- 同比比较使用同一份年报的比较列。五粮液和贵州茅台 2023 年报分别按各自表头选取调整后比较数。兴业银行三份年报的现金流同比栏以文字说明基数符号，底表保留金额，百分比留空。分红使用实际派付口径，保留每股或每十股的分母。
- [机器运行明细（JSON）](../results/collection-coverage.json)包含每份文件的页数、文本质量标记、年报问答结果、季报候选记录和公告检索页。核对底表只在评分时使用。实际工作台从本地 PDF 解析、取数并引用。

## 冻结版本的表现

取数代码固定在 [eb2b179](https://github.com/ThreshoLdnnis/LLM-ResearchAssistant/commit/eb2b179c472e9f1ebabdb8eec547e357117d6d41)。按文档指定公司、年度和合并口径，对三项年度指标使用同一种问法。测试覆盖结构化计算；开放式提问、模型草稿和原因归纳需要独立评估。

| 公司 | 分组 | 5 份 PDF 页数 | 得到同比结果 / 9 次查询 |
|---|---|---:|---:|
| 招商银行 | 开发 | 1,124 | 8/9 |
| 美的集团 | 开发 | 879 | 9/9 |
| 贵州茅台 | 开发 | 429 | 7/9 |
| 兴业银行 | 留出 | 1,132 | 0/9 |
| 格力电器 | 留出 | 742 | 3/9 |
| 五粮液 | 留出 | 458 | 0/9 |

54 次查询中有 27 次完成计算（50%）。这 27 次的两期金额与底表相符，显示到小数点后两位的同比与原表相符。27 次返回证据不足，其中包含兴业银行三份以文字说明同比的现金流记录。这 54 次衡量固定问题的结果覆盖率，不能作为任意投研问题的准确率。

4,764 页中有 4,755 页提取到非空文本。九个无文本页为七张招商银行宣传插页，以及兴业银行的封面和封底；其余短文本或出现替换字符的页面也在 JSON 的 `review_pages` 中标记。针对每份季报和公告分别做文档内 BM25 检索，结果保留候选页。返回相关页和正确还原表格是两项不同的检查。新版还复核了贵州茅台 2024 年报的营业收入、归母净利润和经营活动现金流量净额，原表分别在第 63、64、67 页。

## 本机复现

先按仓库首页安装 Python 依赖。在项目根目录运行以下命令，可从公开披露网站补齐文件并校验哈希。如果已有包含这批 PDF 的 ZIP，只执行第二种导入方式即可。重复运行会复用已经入库的版本。

```powershell
python -m scripts.import_collection
# 或使用本地压缩包
python -m scripts.import_collection "年报数据.zip"
python -m bench.collection --output data/local/collection-coverage.json
python -m unittest discover -s tests -v
```

结果文件独立于原始 PDF，数据库、模型权重、向量缓存和个人查询记录均保存在本机。
