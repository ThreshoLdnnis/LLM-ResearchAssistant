### 每条记录的口径与异常处理

1. **数据键。** 股票代码、集团/母公司/分部、指标原名、期间起止或时点、币种和单位、实际/预测、首次披露/重述版本、文档 ID。跨报告重复的比较数要保留来源，不可重复加总。
2. **数字。** 保存原表文本、原始数值、原单位、标准化数值和换算式。建议标准金额用人民币元；人民币千元 × 1,000、百万元 × 1,000,000。百分数与百分点分别存，1 个百分点等于 100 个基点。仅在同币种、同主体、同期间、同定义下计算变动。
3. **证据。** 保存 PDF 物理页、印刷页（可选）、报表名、行名、完整列表头及必要脚注。叙述句记录发言者、原句及上下文；比较数经重列时应记录年报版本、重述标识及理由原文。
4. **可用时间。** 清单中的日期来自巨潮 PDF 归档路径。真正回答“截至某日”时，还要核对公告的实际披露时间；只有日期时记录时间精度，若涉及交易时点，另存首次可交易日。历史回测仅使用当时可见版本。
5. **缺失。** 对“未披露”“行业不适用”“原表为空”“解析失败”分别标记。三季报缺单季流量时，如需反推，先补同口径半年报，再把累计差额标为派生值并保留两个出处。

### 研报补充范围

完成发行人披露的首轮验收后，每家公司再选 **1 篇 2024 年报点评**（共 6 篇）。限定为年报正式披露日起 30 个自然日内、点名覆盖该公司并有明确机构及日期的中文研报；有多篇时优先选同时包含业务归因与明确预测表的一篇。招商银行已有的东莞证券点评优先复用。采集机构、发布日期、分析师、观点原句、对应报告页及表内实际/预测标记；如有 2025E–2027E 的收入、归母净利润或 EPS，按报告实际覆盖年份存。研报属于附加语料，单独记录来源与使用范围。30 份公司披露之外，另遇重述、分红预案或半年报缺口时再按研究需要补件。

## P1 · 扩库和财务问答

- [ ] **建立覆盖表。** 扩到银行、制造、消费各两家公司，包含首周的制造企业。按六家公司 × 三个完整财年整理 18 份年度报告全文。现有年报摘要单独保留，避免与全文重复计数。按清单补齐三季报与年度分红实施公告，再按研究需要增加修订公告和研报。
- [ ] **把来源和有效时间用于检索。** 区分公司披露、券商预测与助手计算；给更正稿关联前一版本。验收时用更正公告前、后两个截止日问同一个数，逐项核对当日可用版本。
- [ ] **完善指标字段。** 先覆盖营业收入、净利润、归母净利润、经营现金流、毛利率、ROE 和明确定义的资本开支口径。按行业选择适用指标；每家至少选一张完整表逐格核验，保留漏提、误提和币种单位。银行不适用的通用工业指标标为不适用。
- [ ] **把三类问题接到合适的处理方式。** 查数走有来源的指标记录；同比、比率、百分点交给程序计算；原因与风险交给有引文的文本问答。用实际查询记录三条路径的表现；遇到口径歧义时，记录系统采用的口径及出处。
- [ ] **落实引用和拒答。** 表格引用同时展示行、列、单位和页码；文本引用覆盖支持论断的完整句子。以页眉、相同数字但不同指标、材料不足作为反例。点击引用后应能核实答案。

## P2 · 做一次能回答研究问题的主实验

- [ ] **冻结实验样本。** 招商银行、美的集团、贵州茅台用于开发；兴业银行、格力电器、五粮液用于留出验证。先固定文档版本、指标范围和评价口径。问答部分可从实际查阅记录中选取可复核的查询，留出结果只在最终评估时查看。
- [ ] **跑三组配对实验。** A 组直接给模型已核对的证据，B 组使用系统检索结果，C 组在 B 的基础上对数值调用结构化计算。固定查询、模型与日期范围，A、B 采用相同证据长度预算。逐项记录输出差异和对应原文。
- [ ] **单独测扩库效果。** 固定原始查询和来源，分批加入其他企业与相邻年份的报告，检查来源是否选错；另统计新增企业和指标的覆盖率。
- [ ] **复核研究价值。** 按实际可用样本报告取数正确率、引文支持率、材料不足时的处理结果和重大口径错误数，并注明分子、分母、延迟与核对用时。保留逐条证据，说明单人复核的评价局限。
- [ ] **发布实验记录。** 汇总适用范围、主要失误、改进前后的差异及复现命令。对公司、期间、币种或每股口径仍有错配的情形，记录其影响并在留出样本上复核。

## P3 · 进入日常使用时再补的工作

- [ ] **更新与恢复。** 对关注公司做增量导入，记录新披露、更正、解析失败和重复文档。试做一次索引重建与库恢复，再对老问题核对来源和结果。
- [ ] **保留回答版本。** 一次查询记录问题、截止日、文档哈希、检索配置、模型版本、回答及引文。能解释换模型或文档更新后为什么得到不同结果。
- [ ] **按实际读者设置访问。** 若进入团队使用，区分共享披露与个人上传，验证未获访问权的账户无法检索或下载其他人的资料；按来源记录研报的使用与分发范围。

**投入如何决定**　A 组也经常答错，优先改善财务口径、计算或模型；A 对 B 错集中出现，优先修解析与检索；资料清单确实缺少支持文档，再按缺口扩库。
